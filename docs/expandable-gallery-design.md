# 확장형 갤러리 설계

## 목표

모바일 청첩장 안에 하나의 비주얼 오브젝트처럼 보이는 갤러리 미리보기를 두고, 사용자가 어디를 누르든 화면 전체를 덮는 감상형 세로 갤러리로 전환합니다. 복잡한 위치 전환 애니메이션은 사용하지 않고, 단정한 페이드 인/아웃으로 열고 닫습니다.

## 확정된 UX

- 본문에는 대표 사진 3장으로 구성된 갤러리 미리보기를 둡니다.
- 미리보기는 개별 사진 선택 UI가 아니라, 전체가 하나의 터치 대상입니다.
- 대표 3장은 전체 갤러리 이미지 배열의 앞 3장을 사용합니다.
- 닫힌 상태의 배치는 `세로로 긴 1장 + 오른쪽 1:1 사진 2장`입니다.
- 각 사진은 아주 미세한 `translateY` 애니메이션으로 조용히 떠 있는 느낌을 줍니다.
- 별도의 "탭해서 열기" 문구나 아이콘은 두지 않습니다.
- 미리보기를 누르면 본문이 늘어나는 것이 아니라, 풀스크린 레이어가 화면 전체를 덮습니다.
- 풀스크린 레이어는 검은 배경이 아니라, 본문이 뒤에서 흐릿하게 비치는 blur 배경으로 보이게 합니다.
- 레이어는 페이드 인으로 열립니다.
- 갤러리 이미지는 처음에 살짝 흐릿하게 나타난 뒤 또렷해집니다.
- 펼쳐진 뒤 대표 3장은 갤러리 상단의 실제 첫 콘텐츠 블록으로 남습니다.
- 그 아래에는 4번째 사진부터 전체 사진이 `full width` 세로 리스트로 이어집니다.
- 펼쳐진 사진들은 가로폭을 유지하고, 높이는 원본 이미지 비율에 따라 자연스럽게 달라질 수 있습니다.
- 닫기는 우측 상단의 플로팅 X 버튼으로 합니다.
- 닫을 때는 오버레이 전체를 부드럽게 fade/scale-down 처리합니다.

## 컴포넌트 구조

본문 섹션과 실제 인터랙션 본체는 분리합니다.

- `GallerySection`
  - 청첩장 본문 안의 섹션 위치, 제목, 바깥 여백을 담당합니다.
  - `ExpandableGallery`에 전체 이미지 배열을 전달합니다.
- `ExpandableGallery`
  - 미리보기와 풀스크린 전환을 하나의 컴포넌트 안에서 처리합니다.
  - 상태 전환, 스크롤 잠금, 페이드 인/아웃, 닫기 버튼을 담당합니다.

미리보기와 오버레이를 별도 컴포넌트로 완전히 분리하지 않는 이유는, 갤러리 관련 상태와 동작을 한 곳에 모아 단순하게 유지하기 위해서입니다.

## 상태 모델

`ExpandableGallery`는 아래 상태를 가집니다.

- `collapsed`: 본문 안에 3장 미리보기 오브젝트만 보이는 상태
- `expanding`: 풀스크린 레이어가 페이드 인되는 중인 상태
- `expanded`: 풀스크린 갤러리가 열리고 내부 스크롤이 가능한 상태
- `closing`: 오버레이가 fade/scale-down으로 닫히는 중인 상태

레이어가 열려 있는 동안 본문 스크롤은 잠급니다. 오버레이 내부 스크롤은 바로 사용할 수 있으며, 닫힘 애니메이션이 끝난 뒤 본문 스크롤을 복구합니다.

## 레이어 전략

열릴 때는 좌표 기반 확장 애니메이션을 사용하지 않습니다.

1. 사용자가 미리보기 오브젝트를 누릅니다.
2. `phase`를 `expanding`으로 바꾸고 fullscreen `overlay frame`을 렌더링합니다.
3. 오버레이는 페이드 인 애니메이션으로 나타납니다.
4. 짧은 타이머 후 `expanded` 상태로 변경합니다.
5. X 버튼을 누르면 `closing` 상태가 되고, 오버레이는 페이드/약한 scale-down으로 사라집니다.

## 내부 DOM 개념

`ExpandableGallery` 내부는 아래 층으로 나눕니다.

- `preview trigger`
  - 본문 안에 보이는 3장 격자 버튼입니다.
- `overlay frame`
  - `phase !== "collapsed"`일 때만 렌더링합니다.
  - 항상 fullscreen fixed 레이어로 렌더링합니다.
  - 어두운 배경, safe-area, z-index를 담당합니다.
- `hero trio block`
  - 펼쳐진 갤러리 상단의 실제 첫 콘텐츠입니다.
- `remaining image stream`
  - 4번째 이미지부터 끝까지 이어지는 full-width 세로 리스트입니다.
- `close button`
  - 스크롤 콘텐츠 바깥의 고정 컨트롤입니다.
  - 우측 상단에 배치하고 safe-area를 고려합니다.

## 스타일 기준

- 모바일 기준 완성도를 먼저 맞춥니다.
- 본문 미리보기는 작은 썸네일 묶음이 아니라, 존재감 있는 갤러리 섹션으로 보이게 합니다.
- 풀스크린 배경은 `backdrop-filter` 기반의 흐릿한 유리막 느낌을 우선합니다.
- 풀스크린 갤러리의 이미지는 `width: 100%`, `height: auto`를 기본으로 합니다.
- 닫기 버튼은 충분한 터치 영역을 갖고, 어두운 배경 위에서 명확하게 보여야 합니다.
- 미리보기에는 문구나 아이콘 힌트를 추가하지 않습니다.

## 구현 순서

1. 갤러리 이미지 데이터를 `{ id, src, alt }` 형태의 배열로 정리합니다.
2. `GallerySection`이 전체 이미지 배열을 `ExpandableGallery`에 전달하도록 바꿉니다.
3. `ExpandableGallery`의 `collapsed / expanding / expanded / closing` 상태를 만듭니다.
4. 닫힌 상태의 `preview trigger` 격자 레이아웃을 구현합니다.
5. fullscreen `overlay frame` 페이드 인/아웃을 구현합니다.
6. `hero trio block`과 나머지 이미지 세로 리스트를 연결합니다.
7. body scroll lock을 정리합니다.
8. 우측 상단 플로팅 X 버튼과 closing 애니메이션을 구현합니다.
9. 미세한 floating 애니메이션과 reduced motion 대응을 추가합니다.

## 현재 코드에서의 적용 지점

- 현재 `src/sections/GallerySection.tsx`는 placeholder 문자열을 `gallery-card`로 렌더링하고 있습니다.
- `src/data/invitation.ts`의 갤러리 데이터를 이미지 객체 배열로 확장해야 합니다.
- 실제 사진이 아직 준비되지 않았다면, 임시 이미지 에셋을 `src/assets/images/` 아래에 두고 같은 데이터 구조로 연결합니다.
- 스타일은 기존 전역 CSS 구조를 확인한 뒤, 기존 패턴에 맞춰 섹션 스타일 또는 별도 갤러리 스타일로 추가합니다.
