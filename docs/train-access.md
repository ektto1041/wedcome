# 서울 출발 기차 안내 계획

## 목표

서울에서 오는 하객이 서울역 또는 청량리역에서 KTX-이음 열차를 이용해 안동역까지 이동할 수 있도록 예식 안내 섹션에 간단한 교통 정보를 제공합니다.

## 안내 문구 기준

- 서울역 출발: 서울역에서 중앙선 KTX-이음 열차를 이용해 안동역에서 하차
- 청량리역 출발: 청량리역에서 중앙선 KTX-이음 열차를 이용해 안동역에서 하차
- 안동역 도착 후: 전통리조트 구름에까지 차량으로 약 15~20분 이동
- 시간표 확인: 코레일톡 또는 코레일 공식 예매 화면에서 확인

## 코레일 링크

- 공식 예매 화면: https://www.korail.com/ticket/search/general
- 노선이 미리 입력된 공식 공유 URL은 확인하지 못했습니다.
- 청첩장에서는 공식 예매 화면으로 연결하고, 아래처럼 직접 입력하도록 안내합니다.

```text
출발역: 서울역 또는 청량리역
도착역: 안동역
```

## Drawer 표시 구조

- 예식 안내 섹션에 `서울역 출발`, `청량리역 출발` 노선 카드를 표시합니다.
- 각 카드의 `시간표 보기` 버튼을 누르면 화면 아래에서 90% 높이의 모달이 열립니다.
- Drawer에는 현재 공개 시간표 기준의 열차 목록을 정적 데이터로 표시합니다.
- 열차 카드에는 출발 시각, 도착 시각, 소요시간, 열차명, 열차번호, 일반 어른 요금을 표시합니다.
- Drawer 하단에는 코레일 공식 예매 화면 링크와 입력 안내를 둡니다.

## 현재 반영 데이터

- 서울역 → 안동역: 5회
- 청량리역 → 안동역: 14회
- 기준 출처 최종수정일: 2026-07-04
- 데이터 위치: `src/data/trainRoutes.ts`

## 참고한 정보

- 코레일 보도자료: 중앙선 KTX-이음 청량리~안동 운행 및 일부 서울역 연장 운행
- 코레일 예매 화면: 출발역/도착역을 입력해 승차권 조회
- 외부 시간표 서비스: 청량리역에서 안동역까지 KTX-이음 운행 편수와 시간대 참고
