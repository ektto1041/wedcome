# 예식 기본 정보

## 신랑 신부

- 신랑: 박상연
- 신부: 김영진

## 예식 일정

- 일시: 2026년 10월 3일 토요일 오후 4시 30분

## 예식 장소

- 장소: 전통리조트 구름에
- 지역: 경상북도 안동시
- 표기: 경상북도 안동시 민속촌길 190

## 기차 안내

- 서울역 출발: 서울역에서 중앙선 KTX-이음 열차를 이용해 안동역에서 하차
- 청량리역 출발: 청량리역에서 중앙선 KTX-이음 열차를 이용해 안동역에서 하차
- 안동역 도착 후: 전통리조트 구름에까지 차량으로 약 15~20분 이동
- 예매 안내: 코레일 예매 화면에서 출발역을 서울역 또는 청량리역, 도착역을 안동역으로 입력해 조회
- 코레일 예매 링크: https://www.korail.com/ticket/search/general
- 앱 표시 방식: 출발역별 시간표 보기 버튼을 누르면 화면 아래에서 열리는 90% 높이 모달에서 현재 공개 시간표 기준 열차 목록을 확인

## 기차 안내 참고

- 코레일 보도자료에 따르면 중앙선 KTX-이음은 청량리~안동 구간을 운행하며, 일부 열차는 서울역까지 연장 운행합니다.
- 공식 코레일 예매 화면에서 노선이 미리 입력된 안정적인 공유 URL은 확인하지 못했습니다. 청첩장에서는 공식 예매 화면으로 연결하고, 역명을 직접 입력하도록 안내합니다.
